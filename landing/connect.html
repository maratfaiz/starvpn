Happ
Бесплатно · проще всего · iOS 15+
App Store ↗
Шаги подключения
1
Установи Happ из App Store
Найди приложение по названию Happ и установи его как обычную программу.
2
Скопируй ссылку подписки в боте
В боте нажми «Моя подписка» и скопируй ссылку целиком, вместе с https://.
3
Добавь подписку
В Happ открой раздел добавления конфигурации и вставь ссылку. Приложение само загрузит список серверов.
4
Разреши VPN-профиль
При первом подключении iOS попросит добавить конфигурацию VPN — подтверди и введи код-пароль устройства.
5
Подключись
Выбери сервер и нажми кнопку подключения. В строке состояния появится значок VPN.
✅
Готово! Ты защищён. Для проверки открой любой заблокированный сайт.

Streisand
Бесплатно · больше настроек · iOS 15+
App Store ↗
Шаги подключения
1
Скопируй ключ в боте
В мини-приложении бота перейди в раздел «Устройства» → нажми на своё устройство → «Ключ / QR» → нажми «Скопировать».
💡 Ключ начинается с vless:// — он длинный, важно скопировать целиком.
2
Установи Streisand
Скачай приложение из App Store по кнопке выше и открой его.
3
Добавь конфигурацию
Нажми «+» → выбери «Импорт из буфера обмена». Сервер появится в списке автоматически.
⚠️ Если ничего не добавилось — убедись что ключ скопирован, и попробуй ещё раз.
4
Разреши создание VPN
iOS покажет запрос — нажми «Разрешить» и подтверди Face ID или пароль. Это нормально — так работает VPN на iPhone.
5
Нажми «Подключиться»
Выбери добавленный сервер и переведи тумблер в положение ВКЛ. В статусной строке появится значок VPN.
✅
Готово! Ты защищён. Для проверки открой любой заблокированный сайт.
🚀
Shadowrocket
Платно · для опытных · iOS 15+
App Store ↗
Шаги подключения
1
Купи и установи Shadowrocket
Приложение платное; покупка происходит в App Store и к подписке STAR VPN отношения не имеет.
2
Добавь подписку
На главном экране нажми «+», выбери тип Subscribe и вставь ссылку подписки из бота.
3
Обнови список серверов
Потяни список вниз — Shadowrocket загрузит актуальные конфигурации.
4
Разреши VPN-профиль
iOS запросит разрешение на добавление конфигурации VPN при первом включении.
5
Выбери режим
Для полного туннеля поставь Global. Режим Config подойдёт, если нужно пускать через VPN только часть сайтов.
✅
Готово! Ты защищён. Для проверки открой любой заблокированный сайт.

v2rayNG
Бесплатно · Android 5.0+
Google Play ↗
Шаги подключения
1
Скопируй ключ в боте
В мини-приложении бота → «Устройства» → своё устройство → «Ключ / QR» → «Скопировать».
💡 Ключ начинается с vless:// — копируй целиком.
2
Установи v2rayNG
Скачай из Google Play по кнопке выше и открой приложение.
🔧 Нет Google Play? Скачай APK с GitHub — файл v2rayNG_*.apk.
3
Импортируй конфигурацию
Нажми «+» (нижний правый угол) → выбери «Импорт конфигурации из буфера обмена». Сервер добавится в список.
4
Запусти VPN
Нажми кнопку ▶ в центре. Android спросит разрешение — нажми «ОК». В шторке появится значок ключа 🔑 — VPN активен.
✅
Готово! Проверь на 2ip.ru — IP должен измениться.
🖥
v2rayN
Бесплатно · Windows 10 / 11
GitHub ↗
Шаги подключения
1
Скачай архив с ядром
На странице GitHub найди и скачай файл v2rayN-with-core.zip — он уже содержит всё необходимое.
💡 Именно -with-core.zip, не просто v2rayN.zip.
2
Распакуй и запусти
Распакуй в любую папку (например C:\STARVPN\) и запусти v2rayN.exe. Программа появится в системном трее рядом с часами.
⚠️ Если Windows предупредит о неизвестном файле — нажми «Подробнее» → «Запустить». Это нормально.
3
Скопируй ключ в боте
В мини-приложении → «Устройства» → своё Windows-устройство → «Ключ / QR» → «Скопировать».
4
Добавь сервер
В окне v2rayN: меню «Серверы» → «Импорт URL из буфера обмена». Сервер STAR VPN появится в списке.
💡 Можно нажать Ctrl+V прямо в главном окне — работает так же.
5
Включи VPN
Выбери добавленный сервер → нажми «Запустить». Затем кликни иконку в трее → «Системный прокси» → «Авто-настройка». Готово.
✅
Готово! Весь трафик идёт через STAR VPN. Проверь на 2ip.ru.
💻
V2Box
Бесплатно · macOS 12+ · M1/M2/Intel
Mac App Store ↗
Шаги подключения
1
Скопируй ключ в боте
В мини-приложении → «Устройства» → своё macOS-устройство → «Ключ / QR» → «Скопировать».
2
Установи V2Box
Скачай из Mac App Store по кнопке выше и открой. Приложение появится в строке меню вверху экрана.
3
Добавь конфигурацию
Нажми иконку V2Box в строке меню → «Profiles» → «+» → «Import from clipboard». Профиль добавится автоматически.
💡 macOS попросит пароль для добавления VPN-профиля — это нормально, введи пароль компьютера.
4
Подключись
Выбери добавленный профиль и нажми «Connect». Иконка в menubar изменится — VPN активен.
✅
Готово! Весь трафик Mac защищён и зашифрован через STAR VPN.
🐧
NekoRay
Бесплатно · AppImage, любой дистрибутив
GitHub ↗
Шаги подключения
1
Скачай NekoRay
На странице GitHub скачай файл *.AppImage (или архив linux64.zip для своего дистрибутива).
2
Сделай файл исполняемым и запусти
В терминале: chmod +x NekoRay*.AppImage, затем запусти файл двойным кликом или из терминала.
3
Скопируй ключ в боте
В мини-приложении → «Устройства» → своё Linux-устройство → «Ключ / QR» → «Скопировать».
4
Добавь профиль из буфера обмена
В NekoRay: меню «Program» → «Add profile from clipboard». Сервер STAR VPN появится в списке профилей.
5
Включи VPN
Выбери профиль двойным кликом, затем включи режим «System Proxy» или «TUN Mode» в верхней панели.
✅
Готово! Проверь на 2ip.ru — IP должен измениться.
🍏
Happ
Бесплатно · tvOS
App Store ↗
Шаги подключения
1
Установи Happ на Apple TV
На самом Apple TV: App Store → найди Happ → установи.
2
Скопируй ссылку-подписку
На телефоне, в мини-приложении бота → «Устройства» → своё ТВ-устройство → «Ключ / QR» → используй ссылку-подписку (не одиночный ключ) — так проще ввести на пульте.
3
Добавь подписку в Happ
В Happ на Apple TV: «Добавить сервер» → «Добавить подписку» → введи ссылку с пульта (или, если поддерживается, отсканируй QR-код с экрана телефона).
4
Подключись
Выбери сервер «STAR VPN» и нажми «Подключиться».
✅
Готово! Трафик Apple TV идёт через STAR VPN.

3
Добавь подписку в Happ

4
Подключись
Выбери сервер «STAR VPN» и нажми «Подключиться».
✅
Готово! Трафик ТВ идёт через STAR VPN.
