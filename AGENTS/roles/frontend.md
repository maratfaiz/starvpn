# Роль: Frontend

> Ты пишешь то, что реально выполняется в браузере: разметку, стили,
> JavaScript, вызовы к API.

## Зона ответственности

| Папка | Что это | Сборка нужна? |
|---|---|---|
| `landing/` | Сайт — Главная, Тарифы, Wiki, Личный кабинет, Вход, Поддержка, Privacy/Terms, get-vpn | Нет — правишь HTML-файл напрямую |
| `admin/index.html` | Веб-админка, один файл, vanilla JS | Нет |
| `webapp/` | Telegram Mini App, React 18 + Vite + Tailwind | Да — `npm run build:app` |

## Важно понимать про архитектуру

`landing/` и `admin/` — это **не шаблонизируемые файлы**. FastAPI
(`bot/api.py`, функция `_serve_html`) читает их с диска "как есть" при
каждом запросе. Значит:

- Правишь HTML/CSS/JS прямо в файле.
- На сервере после `git pull` достаточно **рестартнуть бота** — сборка
 не нужна.
- Никакого React/Vue/Webpack в `landing/`/`admin/` — это осознанное
 архитектурное решение (см. `AGENTS/decisions/ADR.md`), не добавляй
 build step без обсуждения.

`webapp/` — исключение: реальный React-проект, `webapp/app.html` —
это уже собранный бандл, который реально открывается на `/app`. Меняешь
`webapp/src/` → обязательно гоняешь `npm run build:app` → коммитишь
**обновлённый `webapp/app.html`** вместе с исходниками, иначе прод не
увидит изменений.

## Что можно

- Верстать новые секции/страницы по макету.
- Писать vanilla JS для интерактивности (табы, модалки, формы).
- Подключать существующие backend-эндпоинты (`/api/*`) — см. `AGENTS/architecture/api.md`.

## Что нельзя

- Добавлять фронтенд-сборку (npm/webpack/vite) в `landing/`/`admin/` —
 это ломает всю модель "правишь файл → сразу на проде".
- Хардкодить URL API — используй относительные пути (`/api/...`), сайт
 и API живут на одном домене/порту.
- Реализовывать вызовы к несуществующим эндпоинтам "на будущее" — если
 бэкенда под фичу нет, это либо задача для `backend.md`, либо фиктивный
 UI, который надо явно пометить как заглушку.
- Менять дизайн-токены/визуальный язык самостоятельно — см. `designer.md`.

## Стандартный паттерн страницы

Каждая HTML-страница сайта содержит:
- `#bg-canvas` — фоновая звёздная анимация (копируй код с соседней страницы, не переизобретай).
- `.start-modal-overlay` — модалка выбора канала входа (Через сайт / Через Telegram), общая для всего сайта.
- Общий `<nav>`/`<footer>` — сверяйся с соседними страницами на предмет консистентности ссылок.

## Ключевые файлы для справки

`landing/index.html` (Главная — самый полный пример паттернов),
`landing/wiki/vless-reality.html` (эталон 3-колоночного шаблона Wiki-статьи).
