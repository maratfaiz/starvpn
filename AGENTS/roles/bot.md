# 🤖 Роль: Telegram-бот

> Ты пишешь то, что пользователь видит и на что нажимает **внутри
> Telegram** — команды, кнопки, диалоги.

## Зона ответственности

| Папка | Что это |
|---|---|
| `bot/handlers/` | Роутеры aiogram — один файл = одна фича |
| `bot/states/` | FSM-состояния для многошаговых диалогов (например, оплата) |
| `bot/tasks/scheduler.py` | Плановые задачи (например, напоминания об истечении подписки) |

Разбивка `bot/handlers/`: `start.py` (онбординг/триал), `payment.py` +
`card_payment.py` + `yoomoney_payment.py` + `crypto_payment.py` (оплата
по провайдерам), `devices.py`, `referral.py`, `gift.py`, `profile.py`,
`dashboard.py`, `admin.py` (админ-команды в самом боте, не путать с
веб-админкой), `instructions.py`.

## Что можно

- Добавлять новые команды/кнопки/сценарии.
- Менять тексты сообщений (следи за тоном — см. `ABOUT_PROJECT.md`).
- Добавлять новые FSM-состояния под многошаговые сценарии.

## Что нельзя

- 🚫 Дублировать бизнес-логику, которая уже есть в `bot/api.py` для
  сайта — переиспользуй общие функции/утилиты, не копируй код между
  ботом и API.
- 🚫 Отвечать на `pre_checkout_query` дольше 10 секунд (жёсткое
  ограничение Telegram Payments).
- 🚫 Ломать формат `Marzban`-username (`tg_{telegram_id}`).
- 🚫 Менять бизнес-правила триала/рефералки без сверки с
  `CLAUDE.md` → "Key Business Rules":
  - Триал — 1 раз на `telegram_id`, поле `User.trial_used`.
  - Рефералка — +30 дней за каждых 2 оплативших друзей + бейджи за
    1/5/10/25 друзей (+5/+20/+50/+150 дней).

## Специфика aiogram в этом проекте

- Роутеры регистрируются в `bot/main.py` — новый `handlers/*.py`
  обязательно нужно туда подключить, иначе он просто не сработает.
- Middleware `bot/middlewares/db.py` даёт сессию БД в хендлер,
  `bot/middlewares/ban.py` блокирует забаненных — не обходи их.

## Ключевые файлы

`bot/main.py` (точка входа и регистрация роутеров), `bot/handlers/start.py`
(эталон структуры хендлера).
